## [0.1.0] — 2026-06-01

### Added
- Initial three-tier token architecture (primitives, semantic, component)
- Core colour tokens: brand blue, teal, navy, neutral scale
- Typography tokens: Inter variable font, heading scale h1–h6, body
- Spacing tokens: 4px base grid, 0.25×–10× scale
- Border tokens: default, subtle, strong
- Shadow tokens: sm, md, lg, overlay
- Component scaffolds: Button, Form fields, Nav, Card, Badge
- Pattern scaffolds: Hero, Mega-nav, FAQ accordion
- Governance, naming convention, accessibility, and versioning docs
